# Proyecto-Web-Ejemplo

## Descripción

Proyecto web desarrollado como práctica para aprender el uso de Git y GitHub. El proyecto está compuesto por archivos HTML y CSS que permiten visualizar una página web básica con estilos personalizados.

## Tecnologías utilizadas

- HTML5
- CSS3
- Git
- GitHub

## Cómo clonar el proyecto

Para obtener una copia local del proyecto, ejecuta el siguiente comando en la terminal:

```bash
git clone https://github.com/usuario/Proyecto-Web-Ejemplo.git
```

## Cómo ejecutar el proyecto

1. Clona el repositorio.
2. Ingresa a la carpeta del proyecto.

```bash
cd Proyecto-Web-Ejemplo
```

3. Abre el archivo `index.html` en tu navegador web preferido.

No es necesario instalar dependencias adicionales.

## Estructura del proyecto

```text
Proyecto-Web-Ejemplo/
```

## Ramas del proyecto

Rama utilizada para realizar mejoras en la apariencia visual del sitio web, incluyendo cambios de colores, tipografía y distribución de elementos.
